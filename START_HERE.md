## ⚙️ THE COMPLETE SETUP

### What CCC Is
- **Scheduled freight platform** for Sri Lanka
- **Fixed routes** (Colombo↔Kandy, Colombo↔Galle, etc)
- **Per-package pricing** (route × size, NOT per-km)
- **Consolidation model** (many senders/receivers per lorry)
- **Full tracking** (QR/barcode at 10 lifecycle stages)
- **Delivery proof** (NIC + digital signature + optional photo)
- **Real-time updates** (WhatsApp, SMS, email, push)
- **Public tracking** (no login required)

### Tech Stack
| Layer | Technology |
|-------|-----------|
| Backend | Laravel 11 (PHP 8.3) + Sanctum |
| Database | PostgreSQL 16 + PostGIS |
| Cache/Queue | Redis |
| Realtime/Storage | Supabase |
| Web Frontend | Next.js 15 + TypeScript + Tailwind + shadcn/ui |
| Mobile Sender | Flutter 3.x |
| Mobile Driver | Flutter 3.x |
| Payments | WebxPay |
| Notifications | WhatsApp Cloud API, Notify.lk, Firebase |
| Hosting | DigitalOcean (API), Vercel (Web) |

### Development Plan
